# CliDa2

**CliDa – Manage your clients with ease**

CliDa2 is a mobile application designed to help individuals and small businesses manage client information and track interest calculations in a simple, organized way. The app provides a clean interface with dedicated sections for client management, interest computation, and overall summaries.

🔗 **Website link:** [CliDa3](https://clida3.web.app) 

## 🚀 Features

The application consists of **four main tabs**, each designed for a specific purpose:

### 1️⃣ ClientList

* Displays a list of all clients
* Shows individual **principal amounts** for each client
* Uses **color tags** based on time periods:

  * 🔵 **Blue** → 1 year
  * 🟡 **Yellow** → 2 years
  * 🔴 **Red** → 2.5 years

These visual indicators help users quickly understand investment durations.

---

### 2️⃣ Dashboard

* Click the **magic wand icon** (top-right) to filter and sort data based on your preferences

This tab is divided into three sections:

1. **Summary Section** – Displays total principal amount and total amount
2. **Graph Section** – Line graph showing data year-wise
3. **Insights Section** – Displays sorted values based on their respective types

---

### 3️⃣ Calculator

* Uses **simple interest** for the first 3 years
* Applies **compound interest** for every 3 years *(only after the first 3 years)*

This tab:

* Calculates interest accurately
* Generates the corresponding **Credit Slip**
* Must be used when a client exceeds the **3-year time limit**

---

### 4️⃣ Info

* Backup data
* Restore data into the app
* Remove all stored data
* Change application theme
* Sort the main client list and manage app settings

---

## 📦 Installation

To run this project locally:

```cmd
# Clone the repository
git clone https://github.com/Gangadhararao29/CliDa2.git

# Navigate into the project directory
cd CliDa2

# Install dependencies
npm install

# Run the app in the browser
npm run start
```

You can also run it on an Android or iOS emulator using Ionic CLI.

---

## ▶️ Usage

1. Launch the application
2. Add clients using the **Add Client** tab / using **Try Sample Data** in the welcome screen
3. Calculate interest using the **Calculator** tab
4. View consolidated information in the **Dashboard** tab
